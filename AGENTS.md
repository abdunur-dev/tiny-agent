# tiny-agent Project Instructions

- This project uses Bun, not Node or npm. Always execute commands with `bun run` or `bun test`.
- Source files are in src/. Tests are in test/.
- Keep terminal output minimal and shell-like — avoid heavy formatting, verbose preambles, or emoji spam.
- Follow conventional commits style for any commit messages.
- Always run the full test suite with `bun test` and build with `bun run build` after modifying codebase logic.
